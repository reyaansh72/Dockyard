SYSTEM MAINTENANCE

Cleanup

Reclaim disk space by removing unused Docker resources.

Review before pruning
▣

Stopped containers

Remove all stopped containers. Their writable layers will be deleted.

docker container prune
▤

Unused images

Remove images not referenced by any existing container.

docker image prune -a
⌘

Unused networks

Remove custom networks not used by at least one container.

docker network prune
◈

Unused volumes

Remove unused local volumes. Data in those volumes cannot be recovered.

docker volume prune
⌁

Build cache

Remove build cache that is no longer used by active builds.

docker builder prune
!

Prune actions are permanent. Docker removes only resources that are not currently in use. Review the confirmation before continuing.
